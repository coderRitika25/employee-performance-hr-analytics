# Employee Performance & HR Analytics using Machine Learning

## 📌 Project Overview

This project analyzes employee data using **Supervised and Unsupervised Machine Learning** techniques.

The project predicts employee performance scores and groups employees into different clusters based on their work-related characteristics.

## 🎯 Objectives

* Analyze employee-related data.
* Clean and preprocess the dataset.
* Identify important factors related to employee performance.
* Predict employee performance using supervised learning.
* Segment employees using unsupervised learning.
* Visualize and interpret the ML results.

## 🤖 Algorithms Used

### 1. Random Forest Regression

Used for **Supervised Learning** to predict the employee's average training score.

### 2. K-Means Clustering

Used for **Unsupervised Learning** to divide employees into **3 clusters** based on features such as age, training, rating, experience, and training score.

**Employee Performance for HR Analytics**
